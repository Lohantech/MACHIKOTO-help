#Machikoto-help
# Ja -「日本語」:
このプロジェクトは、ユーザーや参加者をサポートし、MACHIKOTOのホームページを含むすべてのプロジェクトについて私達に連絡できるウェブサイトを構築するものです。詳細については ***https://help.japan-vi.be*** をご覧ください。また、カスタマイズ可能なホームページのプロジェクト（***https://github.com/Lohantech/Wahoo-Japan/blob/main/README.md*** ）もぜひご確認ください。

# En:
This project involves creating a website to assist users and participants, as well as providing a way to contact us regarding all our projects, including the MACHIKOTO homepage. To learn more, visit ***https://help.japan-vi.be***, and also check out our customizable homepage project at ***https://github.com/Lohantech/Wahoo-Japan/blob/main/README.md***
